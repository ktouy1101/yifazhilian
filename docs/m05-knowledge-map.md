## 使用边界

- 条目是科普解释，不替代面诊、检查、诊断或处方。
- 没有收录的内容会明确说“手上没有可靠的本地资料”，不编造。
- 寒暄与自我介绍（你好 / 谢谢 / 再见 / 你是谁）由本地规则回一句人话（provider `local_chitchat`），不走检索、不发外部模型；只有整句都是寒暄时才触发，带具体问题的句子仍走知识路径，急症关键词优先级更高。
- 外部模型只接收当前合成问题和同域片段；不发送病历、身份或聊天历史。
- 语料仍需医院药学/临床/护理审核，正式上线前应逐条核对指南与药品说明书。
