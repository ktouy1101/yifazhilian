> 目标观众：领导 / 评审
> 目的：30 秒内让人记住**三件事**——看病不迷路、病历能整理、纠纷有法可依，并且这三件事是**同一个入口、同一套志愿者体系**在支撑。

## 四、AE 工作流（有 AE 的话按这个做）

```
工程：1080×1920 / 30fps / 28s
├── 00_MASTER            总合成，放所有镜头 + 转场
├── 01_BRAND             徽标出场（预合成），供镜头 1、6 复用
├── 02_DEVICE            手机外框 + 屏幕替换层（预合成）
├── 03_SCREEN_NAV        导诊导航录屏（含路线生长关键帧）
├── 04_SCREEN_RECORD     病历整理录屏（OCR 框关键帧）
├── 05_SCREEN_LEGAL      法律帮扶录屏（气泡 stagger）
├── 06_ENDCARD           数字滚动 + LOGO
└── 07_BGM               音乐 + 转场重音对齐
```

制作规范：

1. **手机外框**：做一个 500×1010 的圆角矩形 + 20px 白边 + 轻投影，屏幕内容用「替换素材」图层，六个镜头共用。
2. **缓动**：所有位移用 `Easy Ease`（F9），入场 0.4s、出场 0.3s；缩放从 0.96→1，透明度 0→100。
3. **错峰**：同类元素（卡片、气泡、字段）用 `offset` 每层延迟 3–5 帧，不要同步进出。
4. **文字**：字幕统一在画面下方 12% 处，字号 44，行距 1.4，出现时带 8px 上移 + 淡入；**一屏不超过 14 个字**。
5. **转场**：只用两种——`Opacity` 交叉溶解（0.3s）和 `Push` 同向位移（0.4s），不要花式转场。
6. **色彩**：画面主色沿用产品色（深蓝 #172B3B / 金 #D8B56A / 青 #0E7C86），保证片子和小程序是同一套视觉。
7. **导出**：`H.264`、`1080×1920`、`30fps`、`VBR 2 pass 8Mbps`、音频 `AAC 128kbps`；另导一版 `1920×1080` 备用。

## 五、没有 AE 的替代路径（我可以在本机直接出片）

本机已具备：Pillow（逐帧绘制）+ imageio-ffmpeg（编码）。做法：

1. 用真实录屏 / 截图作为素材（不是画的假界面）
2. Python 脚本逐帧合成：背景渐变 → 手机外框 → 屏幕内容（带位移/缩放/透明度关键帧）→ 字幕 → 安全区
3. 900 帧（30s×30fps）渲染，再 ffmpeg 编码成 MP4
4. 优点：改动只改脚本参数，重出 1 分钟；缺点：复杂特效（粒子、光效）不如 AE 细腻

## 六、已确认（2026-11-07）

| 项 | 结论 |
|---|---|
| 画幅 | 16:9 横屏 1920×1080 |
| 制作工具 | Adobe AE 不装（需订阅+账号），改为**代码逐帧渲染**；备用 DaVinci Resolve 免费版 |
| 人声 | 不做配音，只做硬字幕 + 背景音乐 |
| 主线 | 志愿者体系：镜头 5 改为"患者提工单 → 志愿者接单 → 回复 → 完成" |
| 音乐 | 用可商用的无版权音乐；若找不到合适曲目，用程序生成极简环境音铺底，不涉及版权 |
