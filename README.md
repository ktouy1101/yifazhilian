# 医法智联学生项目骨架

原生微信小程序 + Python FastAPI 的本机演示工程。重点演示按用途授权、医学/法律分库检索、内部检索参考、紧急事件幂等与真实状态提示。

2026-10-21 M06 **法律知识智能体**第一版闭环：法知页天平开场后直接进入对话，服务端按“分类 → 安全边界 → 本地法条指引或同域检索 → 生成 → 材料/下一步清单”处理。知情同意、病历查阅复制封存、隐私撤回、纠纷途径等高频问题走本地审校文字，不调用外部模型；误诊责任和赔偿金额明确拒绝判断；暴力威胁先劝离开现场并拨打 110/120，不声称已通知任何人；超范围问题转 12348 或律师。回答返回本次主题、合并后的可点击追问、材料清单和下一步，历史回看保留；不再单列问医务科/律师清单，也不返回来源。法律库扩为 3 个演示来源、20 个片段；仍是演示摘录，不是正式法律意见。见 [M06 使用与验收](docs/m06-acceptance.md)。

## 范围

- 小程序内王*兰等预置内容为虚构案例，自动化测试使用合成数据。M03按2026-10-18确认的需求，用于上传和管理本人的真实检验单或病历照片。
- 无配置时使用免费的本地 MockProvider；可在后端本机配置中选用外部 AI。本机已按用户选择配置 DeepSeek，实际请求使用其账户额度；未连接医院、电话、律师或签名服务。
- 后端使用本机 SQLite，默认文件为 `backend/data/yifazhilian.db`，重启后保留授权、会话、体征、病历照片及归档记录。数据文件未加密，生产身份、存储和部署保护仍待完善；M03的本人资料上传要求不等于这些工作已完成。
- 当前可运行链路：演示登录 → 单独授权 → 健康/法律问答 → 撤回后阻断；长按 → 本地接收演示事件 → 状态显示；导航任务 → 私有照片 → 独立审核发布 → 患者照片导览/反馈 → 停用；检验单照片 → 本地OCR/手填 → 原图核对 → 版本归档及更正回查。
- 首页、导诊、法援、我的及聊天页按附件 HTML 原型还原为原生 WXML/WXSS，默认可离线体验合成数据。M03、M04与M11操作需要连接本机服务；电子签署、通知投递、向量检索与完整人工工单仍待实现。
- 设计图与 SQL 是后续开发规格，不代表代码已实现所有生产能力。

## 启动后端

安装 Python 3.11 或更新版本，在工程根目录运行 PowerShell：

```powershell
python -m venv backend/.venv
.\backend\.venv\Scripts\python.exe -m pip install -r backend/requirements-lock.txt
.\backend\.venv\Scripts\python.exe -m pytest backend/tests -q
.\start-backend.ps1
```

日常开发只需运行 `./start-backend.ps1`，它按小程序 `baseURL` 启动后台服务并检查连接；已运行时直接复用，不会重复启动。关闭微信开发者工具不会停止此后台进程，重启电脑后需重新运行脚本。当前地址为 `http://192.168.199.126:8000`，打开该地址的 `/docs` 查看 API 契约。不能只启动 `127.0.0.1` 却让小程序请求局域网地址。详细限制见 [后端说明](backend/README.md)。

SQLite 随 Python 提供，无需安装数据库服务。首次访问需要数据库的接口时会创建数据库及表；`data/` 和数据库文件已被 Git 忽略。可通过 `YIFAZHILIAN_DB_PATH` 指定其他本机文件路径；权限到期与撤回仍会在每次访问时校验，重启不会重置授权。备份请遵循后端说明中的 SQLite 在线备份方法，不要在写入时只复制主数据库文件。

## 启动小程序

M03首次安装运行 `./setup-ocr.ps1`（需要uv），建立独立Python 3.12环境与本地模型；当前电脑已安装验证。模型安装后无需云OCR，原后端`.venv`保持独立。旧“病历查看”授权需要重新阅读新版“本地病历处理”告知。合成测试图在 `backend/fixtures/records-m03/synthetic-lab.png`；详情、故障恢复与接口见[M03文档](docs/m03-acceptance.md)。

用微信开发者工具导入仓库根目录（本机文件夹为 `miniprogram-1`），根 `project.config.json` 已指向 `miniprogram/`，并保留原微信工程的 AppID。原云开发模板已备份到同级目录，不参与本工程运行。不要再导入内部 `miniprogram/` 子目录，否则会读取游客模式配置。

默认打开即进入离线演示，可浏览页面、体验模拟聊天、查看图谱和草稿，不自动登录或授权。需要联调后端时，先启动本机服务，再到“我的 → 设置 → 连接本机服务”，逐项阅读告知并授权后返回健康/法援页面提问。离线模拟回复与本机服务回复明确区分；服务失败不会偷偷改为模拟成功。

演示登录默认开启（`YIFAZHILIAN_DEMO_AUTH=1`）：`/auth/send-code` 固定返回 123456 并在响应里回显 `dev_code`，仅供开发者工具和 M11 全链路测试使用。任何真实用户可达的环境必须设 `YIFAZHILIAN_DEMO_AUTH=0` 并接入短信通道——此时验证码随机生成、响应不含 `dev_code`，客户端改为提示“验证码已发送，请查收短信”并要求手动输入。核验命令：`backend/.venv/Scripts/python.exe .work/self-audit/check_auth.py`。

## 可选真实 AI

后端通过 `AIProvider` 接口切换本地模板与 OpenAI-compatible 服务，具体参数见 [后端说明](backend/README.md)。仅本机 `backend/.env` 保存密钥，已被 Git 忽略；不要把它复制进 `miniprogram/` 或截图。配置示例不含密钥。切换模型或服务地址后重启后端；旧本机授权不能直接用于外部模型，需重新阅读接收方告知并授权。

当前外部问答只发送本次合成提问和本领域检索命中的参考资料，不附带病历、体征、用户标识或聊天历史；本机仍保留历史。急症关键词和未命中资料时返回明确的本地提示。外部接口失败会报错，不伪装成模型成功回复。外部AI问答仍按合成场景验证，M03本人资料不会自动提供给模型；未实现自动可靠去标识化、专业审核或生产合规。

仅在本机调试时，通过开发者工具的“详情 → 本地设置”关闭域名校验；该选择保存在不提交 Git 的 `project.private.config.json` 中。

`127.0.0.1` 只用于开发者工具与后端位于同一电脑的场景。真机及正式环境必须替换为合法 HTTPS 域名，并开启域名校验。本工程不暴露到局域网或公网。

小程序运行无 npm 前端依赖。2026-10-21 夜间最终一次全量运行：后端 166 项通过（当日早些时候记录的 159 项已过期，不要沿用）；前端全量 83 项，受限沙箱 82 通过、1 跳过（M11 真实 HTTP 子进程），完整权限 83 通过；WXML/WXSS 离线编译通过。测试数字只在当次运行有效，`backend/README.md` 与本文档中的旧数字一律视为历史记录，交付前必须重跑 `backend/.venv/Scripts/python.exe -m pytest -q` 与 `node --test tests/*.test.cjs` 后再引用。M11 与身份模块含实际页面处理函数连接临时 Uvicorn 的全链路 HTTP 验收；详见 [M11 验收记录](docs/m11-acceptance.md)。测试使用临时数据库与合成照片，不调用真实模型。M11 账号选择页已做模拟器视觉检查，完整模拟器业务链路和手机真机验收尚未完成；此前其他页面记录见 [视觉验证记录](design-qa.md)。

## 从附件获得的开发事项

原 HTML 的 `openSheet(html)` 与 `openRecord/openVolunteer/openSettings` 的 `openSheet(title, body)` 调用不一致，正文会被忽略，应在继续维护 HTML 时统一签名。本原生骨架不直接运行该 HTML。

附件中的“已履行法定告知”“已电子签署”“已接通”是模拟文案，不能作为真实证据。需要由医生确认、签名验证、接收方回执分别驱动状态。

## 生产设计

- 建议目录及边界见 [架构设计](docs/architecture.md)。
- 仓库对比和官方法源见 [调研记录](docs/research.md)。
- 生产表结构草案见 [数据模型](docs/schema.sql)，尚未应用到演示服务。
- 默认不采集身份证、人脸、精确定位。姓名/电话显示遮罩；健康正文和影像需字段/对象加密；授权患者与经核验医护可按必要范围读取精确临床值。日志只记录元数据。
- 展示遮罩不是匿名化；第三方模型出站需独立完成处理关系、目的、字段、接收方、期限、授权及影响评估。
- 医疗同意文书与个人信息处理授权分开存储；家属紧急联系人身份不自动授予病历访问或代签权。
- 上线前须完成真实身份与关系核验、加密与备份恢复验证、细粒度授权和撤回清理、医院及供应商协议、签署验证、预警审核、通知回执与安全/伦理适用性评估。本机持久化不代表已经实现生产合规存证。

## Git 协作

开源项目仅用于架构调研，未复制其代码。正式引入依赖或源码前逐项核对许可证和模型权重许可。
