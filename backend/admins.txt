# 审核员（管理员）手机号名单：一行一个，`#` 之后是注释。
#
# 这个文件会提交进仓库，因为它不是密钥，而是“谁可以当审核员”的显式决定：
# 改动要经过代码评审，而不是谁在界面上点一下就能获得后台权限。
# 环境变量 YIFAZHILIAN_ADMIN_PHONE（逗号分隔）仍然有效，两者取并集。
#
# 登录后自动获得 reviewer 能力：审核路线、审核志愿者与凭证、管理用户。
# 移除某人时删除对应行即可；下次登录不再授予（已有角色留在 user_roles 里，
# 需要的话用管理台的删号接口处理账号本身）。
#
# 部署自己的实例时，建议把号码写进 backend/.env 或 deploy/env 的
# YIFAZHILIAN_ADMIN_PHONE，不要提交到这里——仓库可能被公开。
