## 进入方式

后端运行并重新编译小程序后，进入“导诊 → 顶部采集 / 审核”。先选择下列角色卡片，再点击底部“进入”按钮；选择卡片本身不会切换身份。预置账号无需手机号、验证码或密码；这是公开合成身份选择器，不是正式账号认证。已绑定手机号或微信的账号即使被设为测试身份，仍使用原登录方式，不允许通过公开账号 ID 免密登录。

| 按钮 | 测试账号 ID | 可以操作 |
| --- | --- | --- |
| 测试体验员 · 小安 | `m11-test-patient` | 返回导诊首页查看两条已发布路线、逐节点看图、提交反馈 |
| 测试采集员 · 小林 | `m11-test-collector` | 领取练习任务、编辑草稿、处理补拍、上传图片、提交审核 |
| 测试审核员 · 小周 | `m11-test-reviewer` | 审核小林提交的路线、退回、发布、停用及查看反馈 |

选择小安并点击“以体验员进入导诊”会直接打开导诊，可看到“大厅导诊台 → 检验科”和“大厅导诊台 → 西药房”。每条路线包含大厅、分岔口、终点三个节点。选择小周可直接处理现成的待审核路线；选择小林可编辑草稿、补拍或领取空白练习任务。不能用小林审核自己的提交。原有三个演示账号折叠在“更多测试账号”中。

## 重新导入

在项目根目录运行：

```powershell
.\backend\.venv\Scripts\python.exe backend/scripts/seed_navigation_demo.py
```

也可使用 `--database C:\path\to\test.db` 指定另一个数据库。脚本先为已有库建立 SQLite 一致性备份，再增量导入；已有测试任务一律跳过，保留你后续的修改、发布和停用状态。它不会重置旧测试数据，也不会修改已有账号权限。脚本自身使用 Mock AI，不调用外部模型或短信服务。

启动后端的网络地址须与 `miniprogram/config/index.js` 一致。当前工程使用电脑局域网地址 `http://192.168.199.126:8000/api/v1`，服务只监听 `127.0.0.1` 时该地址不可访问。局域网调试的启动示例：

```powershell
.\start-backend.ps1
```

脚本按小程序配置监听本机地址，已经运行时复用服务。若电脑 IP 已改变，需同步调整小程序地址及后端允许的主机列表。2026-10-17 登录故障修复时已恢复当前电脑上的后台服务；重启电脑后重新运行脚本。
